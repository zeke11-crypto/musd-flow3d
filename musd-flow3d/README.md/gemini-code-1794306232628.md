# MUSD Flow3D — Enterprise Payment, Receipt Verification & Webhook Engine

Built for **Mezo Buildathon Wave 2 (Track 2: Access and Distribution)**.

MUSD Flow3D bridges on-chain **Mezo MUSD** (`0x118917a40FAF1CD7a13dB0Ef56C86De7973Ac503`) payments with off-chain enterprise automation (n8n, Cloudflare Workers, CRMs, and Telegram/WhatsApp fulfillment pipelines) wrapped in an interactive Three.js 3D Verification Vault.

## Key Features & Wave 2 Architecture

1. **Direct Mezo Testnet (Chain ID `31611`) Execution**:
   - Connects via `ethers.js` to execute native ERC-20 `transfer(address,uint256)` calls against the official 18-decimal MUSD contract (`0x118917a40FAF1CD7a13dB0Ef56C86De7973Ac503`).
   - Built-in **Mezo Protocol Guard** warns users of the 1,800 MUSD minimum principal + 200 MUSD gas reserve (`2,000 MUSD` opening debt floor) when sizing invoices against `BorrowerOperations`.
2. **Cryptographic Receipt Guard (Anti-Replay Protection)**:
   - Queries the Mezo Testnet Blockscout v2 API (`/api/v2/transactions/{txHash}`) and JSON-RPC (`https://rpc.test.mezo.org`) to decode ERC-20 `Transfer` logs.
   - Independently verifies contract address, token decimals (`18`), transfer status, and sender/recipient before locking the `txHash` in a persistent SHA-256 claim ledger to prevent receipt reuse across invoices.
3. **Automated Webhook Dispatcher (n8n & Cloudflare Worker)**:
   - Dispatches verified payment payloads to any webhook endpoint (with CORS-safe fallback) to trigger instant CRM updates, digital product delivery, or Telegram/WhatsApp receipts.
   - Includes `worker.js` (stateless JSON-RPC verifier) and `n8n-workflow.json` for 1-click self-hosted automation.
4. **Interactive 3D Verification Vault**:
   - Built with Three.js and `OrbitControls`. Visually reflects on-chain verification state, dropping physical MUSD tokens into the vault upon verified block confirmation and triggering an anti-replay shockwave if a duplicate transaction hash is submitted.
